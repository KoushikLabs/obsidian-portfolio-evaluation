# Value for Investment (VfI) / Value for Money (VfM)

## What it is

**Value for Investment (VfI)** — and its close relative **Value for Money (VfM)** —
is an approach to making **explicit, reasoned, evidence-based judgements** about
whether the value an investment produces is *good enough* given the resources it
consumes. The modern VfI approach (associated with Julian King) deliberately
moves beyond cost-effectiveness ratios to a **rubric-based evaluative
reasoning** process.

The classic VfM frame uses the **"economy, efficiency, effectiveness, equity"**
("the 4 Es") dimensions; the VfI approach wraps these in an explicit
**evaluative rubric** so that "good value" is defined and defended, not just
calculated.

## How it works

1. **Define what "value" means** for this portfolio (with stakeholders).
2. **Choose criteria** (e.g. the 4 Es, plus portfolio-specific dimensions).
3. **Build a rubric** describing what excellent / good / adequate / poor value
   looks like on each criterion.
4. **Gather mixed evidence** (quantitative cost/results data + qualitative).
5. **Make and justify an evaluative judgement** against the rubric.

## Why it matters for portfolio evaluation

- It answers the question funders and boards actually ask: **"is this portfolio
  worth it?"** — and gives a defensible answer rather than a misleading single
  ratio. This is **open question 3** (success/credibility) meeting **open question
  4** (actionable for funders).
- It is explicitly **rubric-based**, so it inherits rubrics' strength for the
  heterogeneity problem: you can reason about value across unlike grants.
- "**Scaling** Value for Investment" — the theme of conference session
  [[case-studies/VFM01-scaling-value-for-investment|VFM01]] — is about
  applying VfI not to one project but across a whole portfolio/organisation.

## When to use it

- When a funder or incubator needs a **value/worth verdict** on the portfolio for
  strategy, accountability, or resource-allocation decisions.
- Alongside [[methods/contribution-analysis|Contribution Analysis]] (what did we
  contribute?) to connect *results* to *worth*.

## Limitations / cautions

- "Value" is normative — the rubric must be co-designed, or it smuggles in
  contested judgements.
- Resists reduction to a single number; resist pressure to produce one.
- Needs decent cost data, which portfolios often track inconsistently.
