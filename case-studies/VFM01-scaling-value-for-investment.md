## The portfolio being evaluated

Not a single portfolio — the session is about **scaling the Value for Investment
(VfI) approach** so it can be applied across many investments / a whole
portfolio / an organisation, rather than one project at a time.

## Methods used

[[methods/value-for-investment|**Value for Investment / Value for Money**]] —
the rubric-based evaluative-reasoning approach to judging whether value justifies
resources, applied at scale.

## Key challenge addressed

How to make **explicit, defensible value judgements at portfolio scale** — answering
"is this whole body of investment worth it?" without collapsing to a single
misleading ratio. Open question 3 (success/credibility) meeting open question 4
(actionable for funders).

## Relevance to a funder / incubator

High. "Is the portfolio worth it / are we allocating resources well?" is a
question every funder and incubator board asks. A scalable, rubric-based VfI
method gives a defensible answer and a basis for reallocation decisions.
