# Templates

Reusable, copy-and-adapt artefacts for doing portfolio-level evaluation. Each is
designed to be filled in for a *specific* funder or incubator.

## Contents

| Template | Use it to… |
|---|---|
| [[templates/portfolio-evaluation-framework-template\|portfolio-evaluation-framework-template]] | Design a whole portfolio evaluation — theory of change, two-level questions, criteria/rubric, synthesis method. |
| [[templates/cross-case-analysis-matrix\|cross-case-analysis-matrix]] | Synthesise across many grants/ventures into portfolio-level patterns. |
| [[templates/funder-brief-template\|funder-brief-template]] | Communicate findings on one page to non-evaluator funders/boards. |
| [[templates/prompts\|prompts]] | Reusable Claude prompts to draft portfolio evaluation plans, rubrics, syntheses, and briefs. |

## How they connect to the methods

```
portfolio-evaluation-framework-template   ← the master design doc
        │  (its "criteria/rubric" section uses…)
        ├── methods/rubrics
        │  (its "synthesis method" section uses…)
        ├── cross-case-analysis-matrix  ← methods/contribution-analysis, outcome-harvesting
        │  (its findings feed…)
        └── funder-brief-template       ← the actionable output for funders
```

## A note on adapting these

These templates encode the Norad/Itad five-step logic and the Integrity
"bricolage" method philosophy. **Adapt, don't apply blindly** — the whole point of
portfolio evaluation is fitting the approach to a specific, heterogeneous
portfolio. Co-design criteria with the funder so you don't impose ill-suited ones.
