## The portfolio being evaluated

A **multi-sector network** — many organisations across sectors working toward
shared goals. A network is structurally similar to a portfolio: heterogeneous
members, a shared higher-level intent, and the need to evaluate at the collective
level.

## Methods used

- **Collective-impact pillars** — using the collective-impact framework (common
  agenda, shared measurement, mutually reinforcing activities, continuous
  communication, backbone support) as the evaluative scaffolding.
- **Dashboards** — shared measurement infrastructure to track and display
  progress across the network.

## Key challenge addressed

How to **embed evaluation across a network of independent actors** and produce a
collective-level picture using shared measurement — the network analogue of the
portfolio aggregation problem (open questions 2 and 4).

## Relevance to a funder / incubator

High for **incubators and place-based / collaborative funders**. Incubator cohorts
and funder collaboratives often behave like networks; collective-impact pillars +
dashboards are a concrete, reusable way to do shared measurement and embed
evaluation across members.
